# test-ci-cd

Self-hosted Odoo automation testing triggered by GitHub push webhooks.

Start with [the team guide](docs/01-team-guide.md) for the simple explanation.
Use [the technical setup guide](docs/02-technical-setup.md) for installation,
server configuration, webhook setup, testing, email, and troubleshooting.

The CI runs only automated Odoo module tests for modules changed in a commit.
